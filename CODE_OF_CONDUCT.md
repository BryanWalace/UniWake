# Código de conduta

O UniWake é feito para equipes de TI de instituições de ensino, e queremos que o projeto seja um
lugar acolhedor para qualquer pessoa que use, relate problemas, sugira funções ou contribua com
código. Este código se baseia no [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## O que esperamos

- Respeito e cordialidade com todas as pessoas, independentemente de experiência, cargo, instituição,
  identidade ou origem.
- Críticas construtivas, voltadas ao código e às ideias, não às pessoas.
- Paciência com quem está começando: muita gente que usa o UniWake não é desenvolvedora.
- Cuidado com dados: **nunca publique** IPs, MACs, nomes de computadores, senhas ou tokens reais de
  uma instituição, nem dados pessoais de alunos ou funcionários.

## O que não aceitamos

- Ofensas, assédio, linguagem ou imagens discriminatórias ou de cunho sexual.
- Ataques pessoais, provocações ou insistência depois de um pedido para parar.
- Publicar informações privadas de outra pessoa ou de uma instituição sem permissão.
- Divulgar uma vulnerabilidade em público antes da correção (veja o [SECURITY.md](SECURITY.md)).

## Onde vale

Em todos os espaços do projeto: issues, pull requests, discussões, revisões de código e qualquer
lugar onde alguém represente o UniWake.

## Como relatar

Use a opção **Report content** do GitHub no comentário ou na issue (o relato chega ao mantenedor e
ao GitHub) ou fale de forma privada com o mantenedor pelo perfil
[@BryanWalace](https://github.com/BryanWalace). Todo relato é tratado com sigilo.

## Consequências

Conforme a gravidade, o mantenedor pode pedir correção, editar ou remover comentários, ou bloquear
temporária ou permanentemente quem descumprir este código.
