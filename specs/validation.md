## V-T03 Install → update → rollback on Windows CI
CI job **"Update end-to-end (windows)"** (`.github/workflows/ci.yml`, `scripts/ci/update-e2e.ps1`)
passed on run `37405646922` (commit `bb0aad9`) and again, together with every other job, on run `37558479337` (commit `140e3af`): silent install of a 0.0.3 test build, update to 0.0.4
through the panel against a loopback fake release server (download, SHA-256, pre-update backup,
Task Scheduler updater, service restart, health, "update_done" notice), then a broken 0.0.5 that was
rolled back to 0.0.4 with the "Atualização revertida" notice. The **"Installer (windows)"** job
covers silent install, upgrade with data kept, uninstall (AC-001-01a/02/03).

## V-T05 Owner checklist ([manual] and hardware)
1. **AC-001-01b**: install on the controller, reboot it with nobody logged in, confirm the service
   runs and the next schedule fires (Histórico shows "executado").
2. **B-002 Real Wake-on-LAN**: on one PC per model, enable Wake on LAN and disable ErP in the BIOS,
   run the "Preparar máquinas" command, then use **Testar WoL** on its page: expect "Sucesso".
3. **B-003 Other VLANs**: for rooms on other subnets, configure the room's directed broadcast and
   ask the network team to allow it; run Testar WoL on one PC there.
4. **LAN access**: enable it in Configurações, open `https://<ip>:47100` from another computer and
   trust the certificate (README).
