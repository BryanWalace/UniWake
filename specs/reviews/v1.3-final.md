## Architect — approval
- The pull model (ADR-042) is implemented end to end: preparation installs tasks and plain scripts,
  machines check in every minute, keep a signed 14-day agenda and execute it with the hub off; the
  hub never connects to lab PCs and no shared admin password exists.
- Owner decisions Q-1..Q-10 (spec §6b) are each implemented and tested (M19 review lists them).
- Team mode (ADR-048): any team hub answers any machine; orders, reports and agent state replicate;
  agenda versions are content hashes; v1.2 peers get a clear version message.
- Data model stays sync-ready (roadmap §A): new replicated entities go through the change log, and
  `received_at`/sightings stay machine-local.
- Docs: two help pages, README sections, `validation.md` §v1.3, owner checklist in `NEXT.md`.
